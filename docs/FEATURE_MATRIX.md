# NovaPlayer — Feature Matrix & Requirements Traceability

This matrix maps every functional requirement to its implementation phase, priority tier, component dependencies, measurable acceptance criteria, and known system limitations.

## Priority Classification
* **P0 (Must-Have / MVP)**: Essential for core playback, basic library, stability, and minimum viable release.
* **P1 (High)**: Major features providing parity with standard desktop media players (subtitles, audio sync, playlists, network streaming).
* **P2 (Medium)**: Enhanced capabilities (resumable downloads, equalizer, mini-player, advanced metadata).
* **P3 (Future / Enhancement)**: Non-blocking enhancements (advanced visualizers, remote control, custom shaders).

## Feature Matrix Table

| ID | Feature Name | Priority | Target Phase | Dependencies | Measurable Acceptance Criteria | Known Limitations |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **A-01** | Core Local Playback | **P0** | Phase 1 | `LibVLCSharp`, `VideoLAN.LibVLC.Windows` | Successfully plays MP4 (H.264/AAC), MKV (H.265/AC3), MP3, FLAC with audio output and video rendering within 300ms of selection. | Obscure legacy formats (Indeo, RealVideo) require appropriate LibVLC demuxers. |
| **A-02** | Playback Controls & Seek | **P0** | Phase 1 | `IPlaybackService`, `VideoView` | Play, Pause, Stop, Seek to specific timestamp within ±100ms accuracy; Volume adjusts from 0 to 100% with smooth linear curve. | Extreme seeking on high-bitrate keyframe-sparse files may take up to 250ms to align to nearest I-frame. |
| **A-03** | Full-Screen Mode | **P0** | Phase 1 | WPF Window APIs, `VideoView` | Toggling via double-click or F11 expands video across active monitor; controls auto-hide after 2.5s mouse inactivity; cursor vanishes; Escape exits. | Multi-DPI systems must maintain crisp rendering when switching displays. |
| **A-04** | Hotkeys & Input Shortcuts | **P0** | Phase 1 | Input Manager, `RelayCommand` | Space (play/pause), Left/Right (seek ±5s), Up/Down (volume ±5%), M (mute), F (fullscreen) respond within 50ms. | Shortcuts do not fire when an interactive text field in a modal has active keyboard focus. |
| **A-05** | Variable Playback Speed | **P1** | Phase 2 | `LibVLC.SetRate` | Speed adjusts from 0.25x to 4.0x in 0.1x steps; audio pitch correction prevents helium effect between 0.5x and 2.0x. | Speeds above 2.5x may cause audio dropouts if CPU is bottlenecked. |
| **A-06** | Audio Track Selection & Sync | **P1** | Phase 2 | `MediaPlayer.Audio` | Lists all audio tracks with language labels; user can switch active track without stopping playback; audio delay adjustable in ±50ms steps. | Switching tracks on live streams may cause a 500ms buffering silence. |
| **A-07** | Subtitle Engine & Sync | **P1** | Phase 2 | `MediaPlayer.Spu` | Displays embedded subtitle tracks; auto-loads external `.srt`/`.ass` with identical base filename; supports manual subtitle file load; delay adjustable ±5000ms. | Right-to-left (RTL) scripts require system fonts with proper HarfBuzz shaping. |
| **A-08** | Aspect Ratio & Video Scaling | **P1** | Phase 2 | `MediaPlayer.AspectRatio` | Supports Original, 16:9, 4:3, 21:9, Crop to Fill, Fit to Window without aspect distortion. | Non-standard anamorphic pixel aspect ratios rely on container metadata. |
| **A-09** | Error Handling & Recovery | **P0** | Phase 1 | `Serilog`, Result Pattern | If media file is corrupt or unreadable, player halts gracefully, displays user dialog, and logs error without crashing application. | Severely corrupted streams may cause LibVLC to hang until timeout expires. |
| **B-01** | Folder Browsing & Import | **P0** | Phase 3 (Completed) | `System.IO`, SQLite DB | Recursively scans selected directory for supported extensions; indexes 1,000 files in under 2.0 seconds; ignores hidden/system directories. | Network mapped drives (SMB) scanning speed depends on network latency. |
| **B-02** | Library Search & Filter | **P1** | Phase 3 (Completed) | SQLite FTS / indexed queries | User typing in search box filters library items instantly (<15ms latency over 10,000 items) by title, artist, album, format. | Fuzzy spelling matching is not included in initial release. |
| **B-03** | Playlists & Queue | **P1** | Phase 3 (Completed) | `PlaylistManager`, SQLite | Create, save, rename, delete playlists; reorder items; support Loop All, Loop One, Shuffle; import/export standard M3U/M3U8. | Very large playlists (>10,000 items) may take up to 1s to serialize. |
| **B-04** | Playback History & Resume | **P0** | Phase 3 (Completed) | SQLite `history` table | Every played item records timestamp and last position; opening previously watched file prompts: "Resume at mm:ss?" with one-click resume. | Playback within first 3% or last 5% is treated as unstarted / completed. |
| **B-05** | Media Metadata Extraction | **P1** | Phase 3 (Completed) | LibVLC Media Parser / TagLib | Extracts duration, resolution, audio channels, bitrate, ID3 tags (artist, album, title) on background task. | Files without embedded metadata fall back to filename-derived titles. |
| **B-06** | Persistent Settings | **P0** | Phase 1 (Completed) | SQLite `app_settings` | Theme, default volume, hardware acceleration preference, subtitle encoding persist between app sessions. | Reset settings option restores factory defaults. |
| **C-01** | Direct HTTP/HTTPS Playback | **P0** | Phase 4 | LibVLC Network demuxer | Plays direct URL (e.g. `https://domain.com/video.mp4`) with progressive buffering and playback start < 1.5s on broadband. | Servers blocking standard HTTP range requests cannot seek ahead of buffer. |
| **C-02** | HLS & MPEG-DASH Playback | **P1** | Phase 4 | LibVLC adaptive modules | Plays unencrypted `.m3u8` and `.mpd` adaptive live and VOD streams; adapts quality to bandwidth. | Encrypted streams (AES-128 with key authentication) supported only if token is in URL; DRM (Widevine) not supported. |
| **C-03** | Buffering Telemetry | **P1** | Phase 4 | LibVLC `Buffering` event | OSD displays spinning indicator and percentage (0-100%) during network buffering; hides upon playback start. | Packet loss can trigger intermittent re-buffering. |
| **C-04** | Network Fault Tolerance | **P1** | Phase 4 | `IPlaybackService` | On network drop, displays "Connection lost, retrying..." with 3 automatic retries before reporting error. | Timeout set to 15 seconds per retry attempt. |
| **D-01** | Permitted Media Downloader | **P2** | Phase 5 | `HttpClient`, `IStorageService` | Downloads direct media file from HTTP/HTTPS URL into designated downloads folder. | Only permitted direct links; cannot download from DRM or token-locked session streams. |
| **D-02** | Resumable Downloads (.part) | **P2** | Phase 5 | HTTP Range Requests | If interrupted or paused, resumes download from byte offset without redownloading completed parts; renames `.part` to final file on hash/completion check. | Requires server support for `Accept-Ranges: bytes`. Falls back to full restart if not supported. |
| **D-03** | Download Telemetry & UI | **P2** | Phase 5 | `DownloadViewModel` | Real-time bytes received, total bytes, transfer speed (KB/s, MB/s), progress bar, ETA, pause/resume/cancel buttons. | Progress update rate capped at 4 updates/sec to prevent UI lag. |
| **D-04** | Safe URL & Storage Validation | **P2** | Phase 5 | `SecurityValidator` | Blocks private IPs (SSRF), blocks file path traversal in filenames, checks disk space before starting download. | Will throw `InsufficientDiskSpaceException` if free space < content length. |
| **E-01** | Web-DL Container & Codec Spec | **P1** | Phase 2 | LibVLC native decoders | Verified playback of 1080p and 4K MKV/MP4 files encoded in H.264, HEVC 10-bit, AV1, VP9 with HDR-to-SDR tone mapping. | High bit-depth 4K 10-bit on legacy hardware without GPU support may drop frames. |
| **E-02** | Web-DL Multi-Audio & Subtitles | **P1** | Phase 2 | LibVLC demuxers | Correctly parses E-AC3 5.1/7.1 audio tracks, downmixes to 2.0 stereo, renders styled ASS subtitles and PGS graphic subs. | Complex ASS vector drawing animations may cause minor rendering delays on low-end CPUs. |
| **E-03** | Detailed Media Info Modal | **P2** | Phase 4 | LibVLC Media Tracks API | Modal shows container format, bitrate, resolution, framerate, video codec, audio channels, sample rate, subtitle tracks. | Variable bitrate (VBR) files show estimated average bitrate. |
| **F-01** | 10-Band Graphic Equalizer | **P2** | Phase 4 | `LibVLC.Equalizer` | Adjust 10 frequency bands (-20dB to +20dB); 10 presets (Flat, Rock, Pop, Jazz, Bass, Classical, etc.); save custom preset. | Equalizer changes apply with ~50ms latency. |
| **F-02** | Hardware Acceleration Selector | **P1** | Phase 2 | LibVLC configuration flags | Allows selecting Direct3D11, DXVA2, or Software decoding in settings. | Requires player restart to take effect on initialized engine. |
| **F-03** | Mini-Player Mode | **P2** | Phase 4 | WPF Window Styles | Compact borderless floating window; "Always on Top" toggle; minimalist overlay controls; snap-to-corner. | Airspace overlay must resize synchronously with mini-player window bounds. |
| **F-04** | Video Snapshot Tool | **P2** | Phase 4 | `MediaPlayer.TakeSnapshot` | Captures current frame to PNG/JPEG with file naming: `{title}_{timestamp}.png`. | Snapshot resolution matches native video source resolution. |
| **F-05** | UI Themes & Polish | **P1** | Phase 4 | WPF Resource Dictionaries | Dark and Light themes adhering to Windows 11 Fluent aesthetic; smooth control animations; high contrast accessibility. | Dynamic theme switching takes effect immediately without app restart. |
| **G-01** | Structured Logging | **P0** | Phase 1 | `Serilog` | Logs errors, warnings, diagnostic events to rolling files (`logs/novaplayer-.log`); excludes PII and sanitizes URLs. | Max log size 10MB per file, 14-day retention. |
| **G-02** | Global Diagnostics & Crash Dialog | **P0** | Phase 1 | Global Handlers | Intercepts unhandled exceptions, logs full stack trace, presents user friendly dialog with "Restart" or "Copy Report". | Critical unmanaged memory faults in native C DLLs might terminate process before managed handler fires. |
| **G-03** | Standalone Windows Packaging | **P1** | Phase 6 | WiX Toolset v5 / MSIX | Generates standard Windows installer with Start Menu shortcuts, file associations (`.mkv`, `.mp4`, `.mp3`), and native LibVLC bundling. | Admin privileges required for per-machine MSI installation (per-user MSI optional). |
| **G-04** | License Compliance Notice | **P0** | Phase 1 | UI About Dialog | Displays complete open source licenses (LGPL 2.1 for LibVLC, MIT for SQLite/WPF, Apache 2.0 for Serilog). | Source code repository link clearly accessible in UI. |
